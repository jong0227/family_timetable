# 로드맵

각 단계는 "가족이 실제로 써 볼 수 있는 상태"로 끝낸다. 단계를 건너뛰어 기능을 붙이지 않는다.

## M0 — 기반 ✅ (2026-10-23)
- [x] 계층 구조(domain / data / app / features / core/design)와 의존 규칙
- [x] 데이터 모델: 가족 구성원, 자녀(N명, 기관 유형), 시간표 버전, 수정 기록
- [x] 저장소 추상화: 로컬 파일 / Firestore, 스키마 버전
- [x] 버전·수정 기록·되돌리기 규칙 + 테스트
- [x] 권한 정책 한 곳(`Permissions`)
- [x] 디자인 시스템(FacilityFlow 레퍼런스): 토큰, 색 체계, 컴포넌트, 폭 구간
- [x] 앱 틀: 온보딩, 하단 알약 내비, 오늘 대시보드, 아이 추가
- [x] 문서: 아키텍처, 디자인 시스템, Firebase 설정

## M1 — 시간표 입력과 버전 관리 (2026-10-23, 브랜치 m1-timetable-editing)
- [x] 주간 시간표 격자: 교시는 요일끼리 줄 맞춤, 방과 후는 따로 쌓기, 주말 켜기/끄기, 짧은 과목명(즐생·슬생)
- [x] 일정 입력 시트: 종류, 여러 요일 한 번에, 교시 고르면 시간 자동, 겹침 경고, 장소, 메모, 삭제
- [x] 학교 교시 한꺼번에 입력(요일별 1~7교시, 과목 칩으로 빈 교시 채우기, 저장 한 번 = 기록 한 장)
- [x] 학기 목록: 새 학기(다음 학기 이름 자동 추천, 복제/빈), 이름 바꾸기, 지금 쓰기, 지난 학기 보기, 삭제
- [x] 수정 기록 타임라인 → 미리 보기 → 되돌리기(되돌림도 기록)
- [ ] Firebase 콘솔 등록 후 두 폰 실시간 공유 확인

## M1.1 — 첫 실사용 피드백 (2026-10-23, v0.1.1)
- [x] 시간 입력: 숫자만 치면 "1530" → 15:30, 다 치면 다음 칸으로 자동 이동, 1~6시는 오후로 읽기
- [x] 시간 입력: 시계 아이콘 → 5분 단위 휠로 드래그해서 고르기
- [x] 끝 시간은 길이 칩(30분~2시간)으로 한 번에
- [x] 일정 종류에 학교 "방과후" 추가 (스키마 v2)

## M1.2 — 방학 시간표 + 방과후 끝 시각 (2026-10-23, v0.1.2)
- [x] 주간 격자 방과 후 칸에 끝 시각: 좁으면 위 시작·아래 "~16:00", 넓으면 "15:00–16:00" 한 줄
- [x] 시간표 종류 학기/방학(스키마 v3). 방학은 교시 없음, 학기에서 복제 시 학원·방과후만
- [x] 방학 기간을 정하면 그 기간엔 저절로 방학 시간표, 끝나면 학기 시간표로 복귀
- [x] 목록 상태 표시: 사용 중 / 방학 중 / 방학 끝나면 사용 / 7/21~8/18 자동
- [x] 새 시간표 대화상자는 바깥을 눌러도 닫히지 않음(입력 보호)

## M1.3 — 실사용 피드백 2차 (2026-10-23, v0.1.3~v0.1.4)
- [x] 새 일정은 요일을 비운 채로 시작(오늘 요일 미리 선택 안 함)
- [x] 끝 시간 칸에 커서를 둔 채 길이 칩이 안 먹던 문제(키보드가 글자를 다시 보내 "입력 중"으로 오인)
- [x] 주간 시간표 "간단히 / 시간 비례" 전환(이 폰에 기억). 시간 비례는 세로축 = 실제 시각, 겹치면 나란히, 오늘 열에 지금 시각 선
- [x] 일정 종류별 색(학교·방과후·학원·활동·돌봄·기타) + 범례

## M2 — 가족 운영
- [ ] 픽업 담당자(일정마다 누가 데려다주고 데려오는지) + 오늘 화면 표시
- [ ] 알림: 일정 N분 전, 가족이 시간표를 바꾸면 알림
- [ ] 준비물·메모(요일 반복: "수요일 체육복")
- [ ] 회원 관리: 이름 바꾸기, 내보내기, 자녀 회원 연결/해제

## M3 — 자동화
- [ ] 나이스(NEIS) 연동: 학교 검색 → 정규 시간표·학사일정(재량휴업일·방학) 불러오기
- [ ] 홈 화면 위젯("첫째 15:00 피아노")
- [ ] 아이 전용 보기(큰 글씨, "다음 일정" 하나만)
